# Stride

Flutter 桌面效率工具 · Material 3 · SQLite 本地存储 · Windows + Android

## ✨ 功能

**备忘录**
- 树形嵌套（5级子备忘）· 分类标签（8 个默认 + 自定义）· 弹窗创建（Ctrl+N）
- 到期提醒 + 重复提醒（每天/每周/每月）· 后台提醒（关机重启仍触发）
- 全文搜索 · 长按/右键菜单 · 软删除（划线+移底+可恢复）
- 置顶与归档 · 转为 Todo · 按行生成多个 Todo · 关联已有 Todo
- 备忘录转 Todo 自动级联子层级（子备忘录按原层级转成子任务树）

**Todo List**
- 收件箱智能视图（收件箱/已安排/已完成/最近删除）· 子任务（5级嵌套）；各状态严格互斥
- 子任务详情提供进度卡、紧凑层级卡片、同级长按排序和带线性图标的层级操作菜单
- 阶段和本周分别提供未完成/已完成/最近删除；完成与删除按来源归档恢复，并按操作时间倒序
- 最近删除使用独立卡片：显示来源和完整删除时间，恢复按钮常驻，永久删除放入三点菜单
- 最近删除显示实际删除日期，支持恢复和带确认的永久删除；任务不会按 7 天或 15 天自动清理
- Android 仅保留左滑操作，取消滑动完成以避免误触；收件箱长按整卡排序，多选改为明确“选择”按钮
- Android 窄屏（<900dp）单行工具栏、底部筛选统计面板、紧凑任务卡、固定三点菜单与至少 48dp 触控区
- 今日负荷（心力 1/2/3、默认上限 8）· 45 张透明分层素材组成 2.5D 小花精灵，支持空闲/检查/庆祝/困倦/提醒五状态
- 手机端小精灵可拖动并吸附左右边缘，半藏探头、低频可爱走动和本地随机对话不挤占安排筛选区
- 独立左/右方向素材 + 手脚关节步态；今日负荷超限时可改到明天或仍然创建
- 自动完成检测（全部子任务完成→自动标记）
- Android 任务到点使用带 Stride 铃声的全屏提醒；“稍后 10 分钟”跨重启保留，可选每 30 分钟 / 1 小时 / 2 小时全屏巡检今日未完成任务
- 到期提醒 + 重复提醒 · 子任务闹钟 · Android 13+ 权限提示与重启恢复
- 全文搜索 · 右键菜单 · 批量操作（多选完成/删除）
- Android 记忆退出前的备忘录/安排、本周/阶段/收件箱及智能视图，重开直接回到上次页面

**安排模式**
- 手机底部导航为“安排 / 备忘录”；首次默认打开安排的本周页，安排顶部只保留一层“本周 / 阶段 / 收件箱”
- 手机安排页采用紧凑工作区：今日/本周待办与完成摘要、单行周导航、紧凑状态筛选和带具体日期的星期卡片
- 阶段视图按“现在 / 接下来 / 稍后”分组；本周按周一至周日派生展示同一任务
- 本周固定显示周一至周日；今天只显示待办，过去日期展开后显示本周来源的完成与未完成记录
- Android 打开当前周直接定位今天，日期标题采用“周四 · 9/17”短格式；向上仍可查看摘要和过去日期，其他周及 Windows 宽屏从周首开始
- 已过去且没有未完成任务的日期默认收起，仍有未完成任务时自动展开；空日期不显示 `0`
- 空日期压缩为单行但仍可展开添加；“调整日期”模式可把未完成任务拖到任意日期并同步提醒
- 阶段与本周使用分组底部整行快捷添加，只输入名称并自动绑定阶段/日期；安排页无右下角悬浮加号
- 同组任务可同时进行，分组顺序只表示计划，不锁定任务或子任务
- Android 阶段/本周均用长按进行组内排序；跨阶段通过三点菜单，跨日期通过“调整日期”，两个视图共享任务但不共享排序字段
- 收件箱三点菜单为编辑、移到阶段、移到本周、删除；Android 二级选择使用底部面板，Windows 使用锚定菜单
- 本周三点菜单提供编辑、同步阶段、删除；阶段三点增加同步今日，也可跨阶段移动或移回收件箱
- “已安排”平铺显示所有有阶段或日期的未完成任务，只允许查看详情、编辑和调整安排
- Android 的现在/接下来/稍后可独立收起，状态按设备记忆；支持全部收起/展开
- 列表、阶段和本周分别维护自己的有效顺序；筛选排序只提交可见任务
- Windows 三列横向分组 + Android 纵向分组上下滑动，共用同一任务数据

**Android 主屏幕小部件**
- “现在”与“本周”两个独立小部件，支持手机和平板、任意数量任务上下滚动；勾选入口兼容 Android 24+
- 标题加号快捷添加；任务和一级子任务可直接勾选，任务显示子任务完成进度
- 三点菜单按编辑、移动阶段、删除排列；不提供桌面拖拽排序

**通用**
- Android 使用 A6“六序镜花”自适应图标，支持圆形遮罩、旧系统分辨率和 Android 13 单色主题图标
- 深色模式（Ctrl+D，重启记忆）· 快捷键（Ctrl+N 新建 / Ctrl+E 聚焦输入框 / Ctrl+F 搜索 / Ctrl+D 切换主题）
- 长按拖拽排序 · 三点操作菜单 · Windows 右键菜单
- 搜索框智能隐藏（滚回顶部自动出现）
- Todo / 备忘录创建后统一设置时间，可选今天、明天、提醒、重复或直接跳过
- Windows/Android JSON 导出与合并导入（兼容旧版 JSON、导入前自动备份、重复导入去重、关系重映射）
- 通知队列（多通知不丢失）· 时间选择器记忆
- 宽屏左侧导航 / 手机底部导航 · 备忘录宽屏侧栏与手机全屏详情
- 手机 Todo 列表与备忘录通过右下角按钮按需创建；Todo 安排页仅保留分组内添加入口
- Windows / Android SQLite 本地优先同步（Supabase 增量同步，可选 Realtime）
- 标签分类保持原有结构；不启用 Markdown 编辑器
- Android 支持 GitHub Releases 应用内更新：启动后每 24 小时自动检查、手动检查即时反馈、15 秒检查超时、非强制“稍后”、下载进度、完整性/包名/版本/签名校验和系统安装确认
- Android 与 Windows 共用六序镜花应用图标并统一显示为 `Stride`；Windows Release 主程序为 `Stride.exe`

## 🚀 运行

```bash
flutter pub get
flutter run -d windows    # 桌面
flutter run -d <device>   # Android
```

## 📦 打包

```bash
flutter build windows                    # Stride.exe 在 build/windows/x64/runner/Release/
flutter build apk --release              # apk 在 build/app/outputs/flutter-apk/
```

Android Release 必须使用本地正式签名配置 `android/key.properties`；项目不再回退到调试签名。公开更新通过 `scripts/publish_android_release.ps1` 上传到 GitHub Releases，Token、密钥和密码均不得提交。

## ☁️ 启用双端同步

先在 Supabase SQL Editor 执行 `supabase/schema.sql`。当前工作区会自动读取被 Git 忽略的 `assets/config/supabase.json`，普通构建即可启用同步：

```bash
flutter build windows
flutter build apk --release
```

新工作区可复制 `assets/config/supabase.example.json` 为 `supabase.json`；构建参数仍可覆盖本地配置。应用内使用同一邮箱登录，采用启动/回前台/修改后/每 5 分钟/手动同步和 Realtime 唤醒。Windows 数据固定在 `%LOCALAPPDATA%\XiaohuaTodo\todo_list.db`。

## 🛠 技术栈

Flutter 3.44 / Dart 3.12 · SQLite (sqflite + ffi) · Material 3 · Windows schtasks + toast · Android zonedSchedule

当前应用版本：1.3.0+6 · 数据库版本：v23
