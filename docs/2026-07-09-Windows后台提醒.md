# 2026-07-09 Windows 后台提醒（关机重启仍可触发）

## 问题

原来 Windows 用 Dart Timer，app 一关就没了。关机重启后所有提醒丢失。

## 方案

**app 内 Timer + Windows schtasks 双保险**：

| 场景 | 谁负责 | 
|------|--------|
| app 运行时 | Timer（精确到毫秒，处理重复逻辑） |
| app 关闭/关机重启 | schtasks（系统任务计划 + PS toast 脚本） |

Timer 触发时自动删除对应 schtasks，避免双弹。

## 改动

| 文件 | 操作 |
|------|------|
| `assets/scripts/show_toast.ps1` | **新建** — Windows 原生 toast 通知脚本 |
| `pubspec.yaml` | 注册 assets |
| `lib/services/notification_service.dart` | **重写** — 加 schtasks 集成 |

## 工作原理

```
创建提醒 → schtasks /create (一次性任务) + Timer
         ↓                              ↓
    (app 关了)                    (app 运行时)
    Windows 到点执行                Timer 触发
    show_toast.ps1                  → 删 schtasks（防双弹）
    → 原生 toast 弹出              → app 内弹窗
                                   → 重复提醒自动下一轮
```

## 注意

- 需要 Windows 10+ 系统
- 首次运行时 Windows 会请求管理员权限注册 schtasks
- app 启动时 `_loadAll` 会对过期提醒自动跳到下一轮（重复）或清理旧任务（不重复）
