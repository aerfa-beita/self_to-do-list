# 2026-07-09 主题偏好持久化

## 功能

重启后记住深色/浅色选择，不依赖第三方库。

## 实现

利用现有 SQLite，新增 `settings` 表（key-value）：

```sql
CREATE TABLE settings(key TEXT PRIMARY KEY, value TEXT NOT NULL)
```

- 启动时读 `dark_mode`，恢复之前的选择
- 切换时写 `dark_mode`（'true' / 'false'）
- 首次启动无记录，默认跟随系统
