# 2026-07-09 修复 4 个 Bug

## Q1: 备忘录子任务删除延迟

**文件**: `lib/screens/memo_screen.dart`

**根因**: `_softDelete()` 删除子备忘后只调 `_loadRoots()`，父节点的子级缓存仍是旧的。

**修复**: `_softDelete()` / `_restore()` / `_permDelete()` 三个方法在 `_loadRoots()` 后加 `if (memo.parentId != null) await _loadChildren(memo.parentId!);`

---

## Q2: Todo 详情页子任务边框未变大

**文件**: `lib/screens/task_detail_screen.dart` `_buildTree()`

**根因**: 之前改的是 `todo_item.dart` 卡片展开区的 `_subTaskRow()`，但用户看的是详情页的 `ListTile` 子任务行。

**修复**:

| 参数 | 旧值 | 新值 |
|------|------|------|
| Checkbox visualDensity | compact（小号） | 删除→标准尺寸 |
| title fontSize | 14 | 16 |
| contentPadding | H12 V12 | L8 T12 R4 B12 |

---

## Q3: Todo 闹钟不生效

**文件**: `lib/screens/todo_screen.dart` `showAddDialog()`

**根因**: `insertTask` 返回新 ID 但未捕获，`task.id` 为 null → `_scheduleReminder` 中 `task.id!` 抛异常 → `_loadAll()` 也不执行。

**修复**: 捕获 `insertTask` 返回值，`task.copyWith(id: newId)` 后再调度提醒。

---

## Q4: 输入时间后 Enter 不能提交

**文件**: `lib/widgets/add_todo_dialog.dart`

**根因**: 备注 TextField 缺少 `onSubmitted` 和 `textInputAction`。

**修复**: 加 `textInputAction: TextInputAction.done` + `onSubmitted: (_) => _submit()`。
