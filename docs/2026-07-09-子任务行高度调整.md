# 2026-07-09 子任务行高度调整

## 做了什么

Todo 列表卡片展开后的子任务行高度太小，调整为和备忘录条目一致的尺寸。

## 改动

**文件**: `lib/widgets/todo_item.dart` — `_subTaskRow()` 方法

| 参数 | 旧值 | 新值 |
|------|------|------|
| 上下内边距 | 6px | 12px |
| 左侧内边距 | 无 | 8px |
| 右侧内边距 | 无 | 4px |
| 标题字号 | 14 | 16 |
| Checkbox | compact + shrinkWrap | 标准尺寸 |
| PopupMenu 图标 | 16 | 20 |
| 行对齐 | center | start（和备忘录一致） |

## 对照

备忘录用 Card 包裹（自带 margin 6px + padding 14px），子任务行在卡片内部无 Card 外壳。
12px 内边距 + 父级 Card 间距 ≈ 备忘录的 14px 效果。
