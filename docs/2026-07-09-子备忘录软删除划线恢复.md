# 2026-07-09 子备忘录软删除：划线+移底+可恢复

## 做了什么

子备忘录（嵌套在父备忘录下的 memo）删除后，之前是直接消失。改为和子任务一致的行为：划线显示 + 移到底部 + 可恢复。

## 改动

### 1. `lib/repositories/memo_repository.dart` — `getChildren()`

- 移除 `AND deleted_at IS NULL` 过滤条件
- ORDER BY 改为 `deleted_at IS NOT NULL, sort_order ASC, id ASC`

让被软删除的子备忘录继续出现在父节点下方（排在未删除项之后）。

### 2. `lib/screens/memo_screen.dart` — `_buildTree()`

已删除的 memo 禁用编辑/移动/升降/添加子项：

| 操作 | 删除前 | 删除后 |
|------|--------|--------|
| 点击编辑 | ✅ | 无响应 |
| 上移/下移 | ✅ | 禁用 |
| 提升/降入 | ✅ | 禁用 |
| 添加子项 | ✅ | 禁用 |
| 恢复 | — | ✅ 右键菜单 |
| 永久删除 | — | ✅ 右键菜单 |

### UI 效果

- 划线：`MemoItem` 已有 `TextDecoration.lineThrough`（`memo.isDeleted`）
- 移底：`sort_order` 已在 `softDelete()` 中更新 + `ORDER BY deleted_at IS NOT NULL`
- 恢复/永久删除：`MemoItem` 右键菜单已有对应项
