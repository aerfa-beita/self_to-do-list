# 2026-07-09 快捷键扩展

## 新增快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+N` | 智能新建：备忘录Tab→弹窗创建备忘录 / Todo Tab→弹窗创建任务 |
| `Ctrl+F` | 聚焦搜索框（无论在哪个 Tab） |
| `Ctrl+D` | 切换深色/浅色模式 |
