# 2026-07-09 批量操作

## 功能

Todo 列表支持多选 → 批量完成 / 批量删除。

## 使用方式

1. 点击统计行「多选」按钮进入选择模式
2. 每个任务卡片左侧出现 Checkbox，点击卡片 = 选择/取消
3. 底部出现操作栏：「已选 N 项」+「完成」+「删除」
4. 操作完成后自动退出选择模式，刷新列表

## 改动

| 文件 | 操作 |
|------|------|
| `lib/widgets/todo_item.dart` | +selectMode / isSelected / onSelectToggle；选择模式下 Checkbox + 切换 onTap |
| `lib/widgets/memo_item.dart` | 同上 |
| `lib/screens/todo_screen.dart` | +选择模式 / 多选按钮 / 批量完成+删除栏 |
| `lib/screens/memo_screen.dart` | +选择模式 / 多选按钮 / 批量删除栏 |
