# 2026-07-09 重复提醒功能

## 功能

任务/备忘录/子任务 支持重复提醒：不重复 / 每天 / 每周 / 每月。

到期弹通知后自动计算下一轮时间并重新调度。

## 数据模型

三个模型各加 `repeatType: String?` — null=不重复, 'daily', 'weekly', 'monthly'

| 文件 | 改动 |
|------|------|
| `lib/models/task.dart` | +repeatType 字段、构造、序列化 |
| `lib/models/sub_task.dart` | 同上 |
| `lib/models/memo.dart` | 同上 |
| `lib/database/database.dart` | v16 迁移 + onCreate 三个表补 repeat_type TEXT |

## UI

| 位置 | 改动 |
|------|------|
| 新建/编辑任务弹窗 | 提醒时间下方加「重复」下拉 |
| 备忘录编辑弹窗 | 同上 |
| 子任务添加弹窗 | 同上 |
| 子任务编辑弹窗 | 同上 |

下拉选项：不重复（默认）/ 每天 / 每周 / 每月，仅在选择截止日期后才出现。

## 通知层

`notification_service.dart` `scheduleReminder()` 新增 `repeatType` 参数。

Timer 触发后自动计算下一轮：
- daily: +1天
- weekly: +7天
- monthly: +1月
