# 2026-07-10 Android 白屏修复

## 问题

APK 安装后点击白屏，无法进入。

## 根因

`lib/database/database.dart` 无条件调用 `sqfliteFfiInit()` + `databaseFactory = databaseFactoryFfi`。

`sqflite_common_ffi` 通过 FFI 加载本地 SQLite——仅在桌面端（Windows/Linux/macOS）可用。Android 无 FFI 支持，`sqfliteFfiInit()` 导致崩溃 → 白屏。

## 修复

加平台判断：Android 走平台 channel（`sqflite`），Windows 走 FFI（`sqflite_common_ffi`）。

```dart
if (Platform.isWindows) {
  sqfliteFfiInit();
  databaseFactory = databaseFactoryFfi;
}
```
