## 变更清单

### Q2: 分类管理按钮移至横滑最右端
- **文件**: `lib/screens/memo_screen.dart`, `lib/screens/todo_screen.dart`
- 将"分类管理"按钮从统计行移到分类横滑 chips 末尾
- 使用 `ActionChip` 样式（带图标 + "管理"文字），与分类 chips 同一行

### Q3: 搜索框隐藏→滑到顶部出现
- **文件**: `lib/screens/memo_screen.dart`, `lib/screens/todo_screen.dart`
- 搜索框默认隐藏，用户向下滚动 >100px 后自动隐藏
- 滚回列表顶部时自动滑出（`AnimatedSize` 动画）
- Todo 页面新增 `ScrollController` 支持

### Q5: 长按弹出操作菜单
- **文件**: `lib/widgets/memo_item.dart`, `lib/widgets/todo_item.dart`
- `MemoItem`: 在 `GestureDetector` 上添加 `onLongPressStart` → 弹出右键菜单
- `TaskItem`: 在 `InkWell` 上添加 `onLongPress` → 弹出操作菜单
- 提取 `_showTaskMenu` 方法复用右键/长按逻辑
- `_SubTaskRowWidget`: `GestureDetector` 添加 `onLongPressStart`

### Q4: 长按拖拽排序
- **文件**: `lib/screens/todo_screen.dart`, `lib/screens/memo_screen.dart`, `lib/screens/task_detail_screen.dart`
- **Todo 列表**: `ListView` → `CustomScrollView` + `SliverReorderableList`（仅未完成区可拖拽）
- **备忘录树**: 每层兄弟节点 ≥2 时使用 `ReorderableListView` (shrinkWrap + NeverScrollable)
- **子任务树**: 同备忘录方案，重构 `_buildTree` 并提取 `_buildSubTaskTile`

#### 新增 API（Repository + Service）
- `TaskRepository.updateSortOrder(id, order)` + `TaskService.updateTaskSortOrder`
- `MemoRepository.updateSortOrder(id, order)` + `MemoService.updateSortOrder`
- `SubTaskRepository.updateSortOrder(id, order)` + `TaskService.updateSubTaskSortOrder`

### 快捷键: Ctrl+Shift+N 聚焦输入框
- **文件**: `lib/main.dart`, `lib/screens/task_detail_screen.dart`, `lib/screens/todo_screen.dart`
- 全局 `Ctrl+Shift+N` → 聚焦当前 Tab 底部输入框（快速添加）
- `TaskDetailScreen` 内本地快捷键 `Ctrl+N` / `Ctrl+Shift+N` → 聚焦子任务输入框
- `TodoScreen` 新增 `focusInput()` 方法

### Bug 修复: 上下移动按钮无响应
- **文件**: `lib/database/database.dart`
- **根因**: `_fixSortOrderIfNeeded` 只处理 `tasks` 表，`memos` 和 `subtasks` 的 `sort_order` 全部为 0 时 `moveUp`/`moveDown` 找不到相邻项静默返回
- **修复**: 新增 `_fixGroupedSortOrder`，按父级分组修复三个表的 `sort_order`，每次打开 DB 时自动检查
