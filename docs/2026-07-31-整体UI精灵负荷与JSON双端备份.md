## 本次完成

### 整体界面

- Windows 宽屏改为左侧导航栏，手机改为底部导航栏，减少顶部 Tab 占用。
- Todo 顶部改为统一筛选卡：收件箱、今天、未来七天、精灵窝使用紧凑分段导航，分类保持原有数据和名称，仅调整视觉。
- Windows Todo 保留单行任务和右侧详情；窄屏继续进入独立详情页。
- 备忘录详情改为内容优先编辑器：宽屏右侧常驻、手机全屏打开，支持自动保存、日期/提醒/重复、置顶、归档、转 Todo、批量生成和关联任务。

### 小花精灵与精灵窝

- 今日负荷卡内加入 Flutter 原生绘制的小花精灵，不增加图片资源或第三方依赖。
- 负荷分为正常、适中、接近上限、超载四种表情和颜色。
- 小花精灵改为 58px 固定紫色花瓣角色，首次进入后 2～4 秒出现走动/眨眼，之后每 6～10 秒低频随机动作。
- 今天负荷超过阈值后，从“今天”继续安排或从收件箱继续创建，都会出现居中的完整任务飞向精灵动画；任务不会删除，而是写入独立的 `companion_stashed_at` 状态并进入「精灵窝」。
- 点击负荷卡打开设置后，可直接选择“预览动作”，不写入演示数据。
- Snackbar 明确显示任务去向，并提供“安排到明天”；精灵窝内编辑日期也会解除暂存状态。

### JSON 双端备用迁移

- Windows 和 Android 均支持 JSON 导出与合并导入。
- Android 使用系统文件选择器，不要求存储权限，也不增加文件选择依赖。
- 导入前显示任务、备忘录、子任务数量并要求确认。
- 导入前自动在数据库目录的 `backups` 子目录生成当前数据快照。
- 使用 `sync_id`、`revision`、`updated_at` 合并；本地独有记录保留，本地较新记录不覆盖。
- 导入时重新映射任务/子任务/备忘录/关联表的本地整数 ID，避免 Windows 和 Android 自增 ID 不一致造成错链。
- 设置项（含每日负荷上限）随备份迁移；导入内容继续进入 outbox，可在以后配置 Supabase 后上传。

### 已发现并修复的旧清理风险

旧代码会在读取列表时自动永久删除“进入回收区超过 15 天”的任务/备忘录。核对迁移前备份后确认：当前库比旧备份少 1 条已删除任务及其 3 条子任务，原因是自动清理触发，不是数据库迁移。

本次已经取消列表读取时的自动永久清理。以后只有显式执行永久删除才会移除记录。

迁移前备份仍保存在：

`D:\MY_Project\to-do_list\.local-backups\todo_list-before-sync-ui-20260731.db`

恢复旧备份内容会改变当前真实数据库，未自动执行。
