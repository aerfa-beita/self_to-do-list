# Q 版人物关节步态动画

> 日期：2026-08-01  
> 范围：Todo 今日负荷卡内的小花精灵

## 目标

- 以原人物图为身份与服装参考，改成可动画的 Q 版人物。
- 禁止整张人物图片平移冒充走路；头、躯干、手臂和腿必须能独立运动。
- 不引入图片贴图、第三方骨骼库或新运行时依赖。

## 外观设定

- 保留蓬松黑发、大框眼镜、黑色椭圆眼、白色短袖、黑色短裤和右腕绷带。
- 使用柔和渐变、头发高光、面部腮红和脚下状态阴影形成 2.5D 建模感。
- 建模设定稿保存于 `docs/assets/chibi-companion-model-sheet.png`，只作为设计参考，不作为应用运行贴图。

## 实现

- `lib/widgets/workload_companion.dart`
  - 用 `_ChibiCompanionPainter` 原生绘制角色各部件。
  - 上臂/前臂、手肘、手腕、大腿/小腿、膝盖、脚分别计算端点。
  - `AnimationController` 产生循环步态相位；左右腿反相，手臂与腿交叉摆动。
  - 行走时加入身体轻微上下起伏，并保留原有随机眨眼、负荷表情、吞任务和精灵窝逻辑。
  - 往返移动全程保持步态，避免回到原位时滑行。
- `test/workload_companion_test.dart`
  - 覆盖角色渲染、点击和主动步行动画生命周期。

## 说明

当前实现是 Flutter 原生 2.5D 关节角色，不是 Blender/GLB 真 3D 网格。若后续需要任意视角旋转、灯光和骨骼蒙皮，应另建 Blender 模型并导出带 Walk 动画的 GLB；本次实现已经满足小尺寸 UI 内“不是贴图平移、四肢像人一样走动”的要求。
