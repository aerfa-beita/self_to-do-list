# 创建时间向导、跨屏精灵与旧版 JSON 合并

> 日期：2026-08-01  
> 版本：1.2.1+4 · DB v19  
> 平台：Windows + Android

## 完成功能

### Todo / 备忘录两步创建

- 第一步先填写任务标题或备忘录内容，保留原分类和任务心力值。
- 第二步统一弹出“设置时间”，支持今天、明天、自选日期、提醒时间和重复周期。
- “跳过时间”会直接创建无日期记录；返回则取消本次创建。
- 快速输入框和完整新建弹窗都走同一时间向导。
- Todo 快速创建选了提醒后会立即登记通知。
- 修复备忘录旧弹窗只登记通知、没有把时间持久化到数据库的问题。

### Q 版人物跨屏吞任务

- 复用 `_ChibiCompanionPainter` 的关节步态，不引入第二套人物素材。
- 今日负荷超限并选择“交给小精灵”后，人物从负荷卡出发，走到任务卡旁，吞下任务，再走向精灵窝。
- 动画分为赶路、吞下、返回三个阶段，任务卡在吞下阶段缩小消失。
- 底部结果横幅保留“安排到明天”，新增显式关闭按钮，8 秒后也会自动结束。
- 任务只设置 `companion_stashed_at`，不会被删除。

### Windows Release JSON 合并到 Android

- 兼容旧版导出 JSON：即使没有 `format_version`、`sync_id`、`updated_at` 和 `revision` 也能导入 DB v19。
- 旧记录会得到确定性 UUID；同一备份重复导入不会重复产生任务或备忘录。
- 合并前自动把 Android 当前数据备份到数据库旁的 `backups` 目录。
- 合并保留手机本地记录，并重映射任务、子任务、备忘录父子关系和 Todo/备忘录关联。
- 私人 JSON 不嵌入 APK；交付采用 APK 覆盖安装后，再在应用中选择“合并导入 JSON”。

## Android 数据验收顺序

1. 不卸载手机旧版应用；直接用新 APK 覆盖安装。
2. 若系统提示签名不一致，停止安装，先保留旧应用并导出手机 JSON；禁止卸载后直接装。
3. 启动 1.2.1，先确认手机原任务和备忘录仍在。
4. 把 Release JSON 发到手机，打开应用菜单，选择“合并导入 JSON”。
5. 预览应显示任务 5、备忘录 7、子任务 46；确认后开始合并。
6. 合并完成后同时检查手机原数据与 Windows Release 数据。
