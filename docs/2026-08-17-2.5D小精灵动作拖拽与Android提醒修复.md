# 2.5D 小精灵动作、拖拽与 Android 提醒修复

> 日期：2026-08-17

## 目标

- 用最终分层素材替换单张 WebP 的运行表现。
- 走路时真实摆动手脚并保留落地感，不再只有整个人物平移。
- 手机端支持拖动小精灵，松手后吸附左右边缘并记忆位置。
- 超限任务改成靠近、蹲下、双手抓取、抱回、放下的连续动作。
- 修复 Android 通知权限和重启后提醒恢复链路。

## 素材核验与接入

- 最终 ZIP：69 个条目，SHA-256 `C10B826554E9994BEC84113AAC2B1B92E909851C7D1800AD53BA5E28BD55A6FF`。
- 运行时接入 front / left / right 各 15 个透明 PNG，共 45 个；左右方向使用独立素材，禁止镜像。
- 运行时读取 `mascot_rig.json` 的 512×512 坐标、旋转轴、层级及手脚锚点。
- 三圈绷带、单耳环、解剖学左右规则沿用正式包；动作参考图仅归档到 `docs/assets/mascot_2_5d/`，不进入应用运行资源。

## 动作实现

- `companion_rig_service.dart` 负责解析和缓存骨骼配置。
- `rigged_companion.dart` 按 zIndex 组装部件，开放手/抓握手根据动作切换。
- 走路使用左右腿反相、前臂反摆、抬脚、头部与耳环次级摆动，并添加支撑脚方向的根节点补偿。
- 搬运流程分为接近、伸手、双手抓稳、抬起、抱回、放下；任务卡绑定 `taskCarryAnchor`，不会再缩小飞入口中。

## 手机端交互

- 小精灵可直接拖动；拖动结束吸附到最近的左/右屏幕边缘。
- 左右边缘都支持半藏探头和对话气泡。
- 归一化位置写入 SQLite `settings.companion_position`，应用重启后恢复。

## Android 提醒修复

- 初始化时请求 Android 13+ 的通知权限；拒绝或异常时保留可见状态，不再静默失败。
- 增加 `RECEIVE_BOOT_COMPLETED`。
- 注册 `ScheduledNotificationReceiver` 与 `ScheduledNotificationBootReceiver`，覆盖开机、应用更新及常见快速启动广播。
- 继续使用 `inexactAllowWhileIdle`，不申请会跳转系统设置的精确闹钟权限。
