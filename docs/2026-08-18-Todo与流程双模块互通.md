# Todo 与流程双模块互通

> 日期：2026-08-18  
> 数据库：v20  
> 范围：Todo 列表、流程模块、顺序步骤、双向互通、Windows/Android 自适应

## 目标

- 保留现有 Todo 列表及全部能力。
- 新增独立“流程”入口，用流程图表达需要按顺序完成的任务。
- Todo 与流程使用同一条任务和同一组子任务，不复制数据。

## 实现

### 数据与迁移

- `tasks` 新增 `task_mode`：`normal` 为普通 Todo，`flow` 为流程任务。
- 数据库从 v19 升级到 v20；旧任务迁移后默认保持 `normal`。
- 流程步骤继续使用 `subtasks`，排序、提醒、软删除、JSON 备份和云同步沿用原链路。
- 子任务进度忽略已软删除记录，避免删除步骤后阻塞流程完成。

### 双模块互通

- Todo 模块显示所有任务；流程任务额外显示“流程”标记。
- 流程模块只显示 `task_mode = flow` 的任务。
- Todo 菜单支持“转为流程 / 转为普通 Todo”，原子任务直接成为流程步骤。
- 两个模块编辑和完成的是同一条记录，标题、步骤、完成状态和进度实时一致。
- 流程任务不能从 Todo、备忘录关联或批量操作中绕过步骤直接完成。

### 顺序规则

- 只有第一条未完成的顶层步骤可以完成。
- 后续步骤显示锁定状态。
- 退回时只能从最后一个已完成步骤开始。
- 全部有效步骤完成后，主任务自动完成。
- 已完成流程可从 Todo 重新打开，最后一步恢复为当前步骤。

### 界面

- 宽屏使用横向节点和箭头，可横向滚动。
- 手机使用纵向时间线，避免节点被压缩。
- 流程支持多行快速创建、添加步骤、编辑步骤、删除步骤、修改流程名称和转回普通 Todo。
- 主导航新增“流程”，Windows 使用侧边导航，Android 使用底部导航。

## 真机验收清单

1. Todo、流程、备忘录三个入口都能正常切换。
2. 在流程模块多行创建 4 个步骤，Windows 显示横向节点，Android 显示纵向时间线。
3. 未完成第一步时点击第二步，第二步保持锁定；完成第一步后第二步解锁。
4. 回到 Todo，确认同一任务带“流程”标记，步骤和进度一致。
5. 从 Todo 修改标题或步骤，再回流程确认同步；流程完成一步后回 Todo 再确认同步。
6. 测试“转为普通 Todo”和“转为流程”，确认任务与子任务不重复、不丢失。
7. 关闭并重启应用，确认流程类型、步骤顺序和完成进度保持。
8. Windows/Android 同账号同步后，确认 `task_mode` 和步骤状态双端一致。
