# Todo 列表与安排模式

> 日期：2026-08-19  
> 范围：Todo 单模块双视图、安排分组、双向互转、Windows/Android 自适应

## 目标

- 移除主导航中的独立“流程”入口。
- Todo 顶部使用“列表｜安排”切换，同一任务只保存一份。
- 列表存放未安排任务；安排视图使用“现在、接下来、稍后”三个有序分组。
- 同组任务表示可以同时进行，分组顺序只表达计划，不限制任务开始或完成。

## 实现

- `task_mode` 继续作为轻量安排元数据：
  - `normal`：未安排，显示在列表。
  - `plan_now`：现在。
  - `plan_next`：接下来。
  - `plan_later`：稍后。
- 旧 `flow` 数据读取时自动映射到“现在”，不新增任务表、不复制任务。
- “加入安排”默认进入“现在”；安排任务可移动到其他分组或“移回列表”。
- 安排视图支持组内拖动排序，排序写回原任务并进入同步队列。
- 移除流程任务的顺序完成限制，主任务和子任务均可自由勾选。
- Windows 使用三列横向分组；Android 使用纵向分组并上下滚动。
- 安排视图底部提供可折叠“未安排任务”，可直接把列表任务加入任意分组。

## 界面

- 主导航只保留“备忘录、Todo”。
- Todo 顶部固定显示“列表｜安排”分段按钮。
- 安排任务行仅保留勾选框、标题、移动菜单和拖动柄。
- 不显示箭头、锁图标、复杂关系设置或自由画布。
