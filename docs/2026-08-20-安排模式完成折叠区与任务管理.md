# 2026-08-20 安排模式改造（完成折叠区 + 任务管理 + 详情页分组切换）

## 背景

小花先生验收安排模式（现在/接下来/稍后）提出三处问题，经方案讨论确认：

1. 完成的任务留在原列只画横杠，占位置 → **收进底部"已完成 · N"折叠区**
2. 安排视图的任务完全无法改名/删除 → **行菜单加编辑/删除（软删除+确认框）**
3. 想"先建名字、点入后选分组" → **详情页顶部加 现在/接下来/稍后 三段切换**（点任务进详情页即可换组）

方案阶段小花先生确认：底部折叠区 / 加管理入口 / 详情页三段切换。

## 改动

### `lib/screens/todo_screen.dart`（数据层）

- `_arrangedTasksForMode` 拆为 `_arrangedUndoneForMode` / `_arrangedDoneForMode`：列只收未完成，折叠区收已完成（均按 taskMode 过滤 + sortOrder 升序）。
- `_reorderArrangement` 只重排未完成行；已完成行保留原 sortOrder 不重编号不写库（折叠区按原序展示，恢复回列顺序不变）。
- 新增 `_confirmDeleteArranged`：确认框 → 复用 `_softDelete`（软删除可恢复）。
- `_openDetail` 改分支：仅列表模式桌面走侧栏；**安排模式任何宽度一律进详情页**（修掉安排模式桌面点行无反应的旧问题）。

### `lib/screens/flow_screen.dart`（纯展示层）

- `TaskArrangementView` 新增 `doneNowTasks/doneNextTasks/doneLaterTasks`、`onEditTask/onDeleteTask`。
- 新增"已完成 · N"折叠区 `_doneSection`：按 现在/接下来/稍后 分组小节展示（仿未安排面板结构），行复用 `_ArrangementTaskRow(draggable: false)`，取消勾选即恢复回原列；N=0 显示"还没有完成的任务"。桌面插在三列与未安排面板之间，移动端在"稍后"段与未安排面板之间。
- `_ArrangementTaskRow` 菜单重构：**编辑** / 移到现在·接下来·稍后（隐藏当前组）/ 移回列表（有条件）/ **删除**（error 色）；tooltip 改"任务操作"。
- 空态文案"暂无任务"→"暂无未完成任务"（避免列内只剩已完成时误导）。
- 未安排面板行顺带补上编辑/删除能力。

### `lib/widgets/todo_item.dart` + `lib/screens/todo_screen.dart`（列表菜单直接三选分组）

按小花先生最终确认的产品形态：**分类不需要点进任务改，直接在任务名称的菜单里三选**。

- `TaskItem` 的 `onToggleFlowMode`（加入安排/移回列表二选）改为 `onMoveToMode: ValueChanged<String>`。
- 三处菜单（右键 `_showTaskMenu` / 移动端左滑底部菜单 / 右上角三点 `_buildMenu`）统一为：
  - 未安排任务 → **移到：现在 / 移到：接下来 / 移到：稍后** 三项
  - 已安排任务 → **移回列表**
- 回调统一走既有 `_moveTaskToMode`（todo_screen，setTaskMode + SnackBar），删除 `_toggleFlowMode`。
- 安排视图行尾三点菜单上一轮已具备同样三项（现在/接下来/稍后），双端入口一致。

### `lib/screens/task_detail_screen.dart`（详情页回归子任务单页）

- 移除「安排/子任务」双 Tab 与分类卡片（小花先生确认不需要点进任务分类）。
- 恢复为原子任务管理单页 + AppBar **只读分组 Chip**（展示当前所在组，不可点）。
- 备忘录（note）仍在正文顶部。

## 数据模型

**无 DB 迁移**。完全复用 `taskMode` + `completedAt`（软删除沿用 `deleted_at`），同步兼容。

### 测试踩坑（重要）

- `showDialog` 的 Future 要等 **route 退出动画结束**才 resolve：点对话框按钮后必须 `pumpAndSettle()` 推完动画，否则 `_softDelete` 永不执行（settle 轮询只 `pump()` 不推进动画时钟）。
- `Process.run`（schtasks，软删除里 `_cancelReminder` 触发）在 testWidgets 的 FakeAsync zone 里不会自动完成，需要 `runAsync` 窗口让真实异步跑完——统一用轮询 `settle()` 辅助函数。
- 软删除任务查询用 `getDeleted()`，不在 `getActive()` 里。
