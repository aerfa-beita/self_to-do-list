# 2026-08-24 Android 后台提醒保障：精确闹钟 + 小米白名单引导

## 背景

小花先生要求"不打开 app 也能后台提醒"。此前 8/24 已修复 release 包 R8 丢泛型导致的排程失败（`Missing type parameter`，提醒根本没排进系统），本次为**后台提醒的可靠性加固**。

先澄清一个关键事实：`zonedSchedule` 本就是 Android 系统 AlarmManager 排程——**app 进程被杀/完全划掉也会到点弹通知**，开机/更新后由 `ScheduledNotificationBootReceiver` 恢复（manifest 早已声明）。"不打开 app 也能提醒"在设计上一直成立，之前收不到纯粹是排程失败。

小花先生手机是**小米/红米**（MIUI/澎湃 OS），后台限制严格，实测场景"一直开着 app 也收不到"与 R8 根因吻合（排程失败与开不打开 app 无关）。

## 改动

### 1. `android/app/src/main/AndroidManifest.xml` 加三个权限

- `USE_EXACT_ALARM`：Android 13+ 自动授予（闹钟/日历类应用），无需用户操作
- `SCHEDULE_EXACT_ALARM`：Android 12/13 生效；14+ 有 USE_EXACT_ALARM 时系统忽略
- `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`：电池优化白名单弹窗所需

侧载无 Google Play 审核问题；将来上架 Play 需评估 USE_EXACT_ALARM 政策合规。

### 2. `lib/services/notification_service.dart`

- `zonedSchedule` 的 `androidScheduleMode`：`inexactAllowWhileIdle` → **`exactAllowWhileIdle`**（Doze 下也准点）
- 排程前 `canScheduleExactNotifications()` 检测：无精确闹钟权限时**降级 inexact，不抛错**
- 新增两个方法（**坑**：flutter_local_notifications 18.x 没有电池优化 API，`isIgnoringBatteryOptimizations`/`requestIgnoreBatteryOptimizations` 是 19.x 才有——不升级插件，改走**原生 MethodChannel** `todo_list/battery_optimization`，MainActivity.kt 用 `PowerManager.isIgnoringBatteryOptimizations` + `ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`（fallback `ACTION_IGNORE_BATTERY_OPTIMIZATION_SETTINGS` 列表页））：
  - `isIgnoringBatteryOptimizations()`：是否已入白名单（非 Android 恒 true）
  - `requestIgnoreBatteryOptimizations()`：弹系统框申请白名单（非 Android no-op）

### 3. `lib/screens/todo_screen.dart` + `lib/screens/memo_screen.dart`

设提醒**成功**且未入白名单时，SnackBar「为保证锁屏/后台也能准时提醒，建议允许后台运行」+ action「去设置」→ 弹系统白名单授权框。每进程只提示一次（复用/新增 `_reminderWarningShown` 内存标记）。

## 明确不做

- **不做前台服务常驻**：zonedSchedule 不需要进程活着，前台服务费电 + 常驻通知，零收益
- **不做 MIUI 自启动 Intent 跳转**：MIUI 各版本路径不稳定（`miui.intent.action.OP_AUTO_START` 等），SnackBar 文案引导更稳
- **不改 Windows 链路**：schtasks 已系统级

## 验证

1. `flutter analyze` 无新警告 + 全量测试通过
2. 装新 APK 后按序验证（小米机）：
   - 打开 app 设 2 分钟后提醒 → 到点收到（R8 修复效果，最先确认）
   - **完全划掉 app**（最近任务滑掉）设提醒 → 到点收到（系统级排程）
   - 重启手机设提醒 → 到点收到（BOOT_COMPLETED 恢复）
   - 锁屏过夜 → 到点收到（Doze 下 exactAllowWhileIdle）
   - 设提醒时若弹"允许后台运行"引导 → 授权后重复测试
3. 若仍收不到：小米"省电策略→无限制 + 自启动"需手动开启（设置→应用→应用管理→目标应用）
