# 阶段与本周双视图

## 已完成内容

- Todo 一级入口由“安排”改名为“阶段”。
- 阶段页面增加“阶段 / 本周”左右切换；同一时刻只显示一个视图。
- “现在 / 接下来 / 稍后”的新建按钮移到分组标题，删除分组底部重复新建入口。
- 本周按本地时间的周一至周日分组，动态标记“今天”。
- 本周默认只显示今天和有任务的日期；其他空日期合并为“其余 N 天”，不显示零计数。
- 本周日期分组支持收起；展开空日期入口后可直接向指定日期新建任务。
- 普通列表、阶段和本周任务都固定使用明确的三点图标与 48dp 触控区域。
- 删除无效排序撤销状态及按钮；排序、移动和错误提示改为可关闭的浮动反馈。

## 当前架构

- `TodoScreen` 继续持有任务数据、创建流程、日期写入、排序和持久化回调。
- `TaskArrangementView` 只负责阶段/本周派生展示和本机 UI 状态。
- 阶段归属继续读取 `Task.taskMode`；本周归属直接读取 `Task.dueDate`。
- 未新增表或字段，DB 保持 v20；同步与 JSON 格式不变。

## 关键边界

- 从阶段分组新建：预设阶段，日期仍由时间向导决定。
- 从星期分组新建：预设目标日期，不自动改变任务阶段。
- 普通列表任务只要截止日期位于本周，也会出现在本周视图。
- 本周已完成任务使用同一任务记录并进入独立折叠区；清空仍为可恢复的软删除。
- 本周以周一 00:00 至下一周周一 00:00 为范围，使用设备本地时区。
