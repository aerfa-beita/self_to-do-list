# Android 小部件删除作用域编译修复

> 日期：2026-09-15
> 影响文件：`WidgetQuickTaskActivity.kt`

## 问题

Android Release 在 `compileReleaseKotlin` 阶段失败：

```text
WidgetQuickTaskActivity.kt:108:63 Unresolved reference 'kind'
```

小部件删除操作改为记录 `stage/week` 来源后，`confirmDelete()` 调用了 `softDeleteTask(taskId, kind)`，但没有接收 `kind` 参数。

## 修复

- `showMenu()` 从 Intent 读取 `EXTRA_KIND`，缺失时按 `KIND_NOW` 兼容。
- 调用删除确认时显式传入 `kind`。
- `confirmDelete()` 增加 `kind: String` 参数，再交给 `WidgetTaskStore.softDeleteTask()`。

该改动不改变数据库结构，也不改变 Flutter 页面逻辑，只补齐 Android 原生小部件菜单的参数链。

## 验收

- Codex 托管子进程重试后在进入 Kotlin 编译前触发既有 `Unable to establish loopback connection`，无法代替普通终端完成编译确认。
- 小花先生需在原普通终端重新执行 `flutter build apk --release --no-pub`，以 Kotlin Release 编译结果为准。
- 构建成功后核对 APK 更新时间，再进行小部件“现在/本周”删除来源真机验收。
