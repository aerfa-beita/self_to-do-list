# 子任务详情页统一改版

> 日期：2026-09-16
> 范围：Android 优先，同时统一 Windows 详情页和任务卡展开预览
> 视觉方向：已确认的紧凑任务工作区

## 已完成内容

- 详情页新增任务进度卡，集中显示剩余数量、完成数量和进度条，删除顶部重复的完成统计。
- 子任务改为紧凑圆角卡片，统一圆形完成按钮、两行标题、省略显示和日期状态样式。
- 同级子任务在详情页使用长按拖动排序；三点菜单删除“上移 / 下移”，避免菜单和拖动提供重复操作。
- 三点菜单统一为 20dp Material 线性图标、至少 48dp 触控区，顺序为编辑、层级操作、分隔线、删除。
- 层级操作改为“添加下级 / 提升一级 / 设为上一项的下级”，用词直接说明结果。
- 底部添加栏改为安全区内的填充输入框和 50dp 添加按钮，兼容系统手势区域。
- 空状态、任务备注和任务卡展开预览统一使用主题色，不再使用表情符号充当图标。
- 修复任务卡展开子任务时 hover 灰色边框突兀的问题，改为低对比度圆角表面反馈。

## 当前交互

- 点击标题：编辑子任务。
- 点击圆形勾选：完成或取消完成。
- 点击箭头：展开或收起下级。
- 长按并拖动：只调整同一父级内的顺序，不改变层级。
- 三点菜单：编辑、添加下级、提升一级、设为上一项的下级、删除；已删除项只显示恢复和永久删除。
- Windows 右键菜单与三点菜单使用同一组操作和顺序。

## 架构与维护

- 详情页布局与交互集中在 `lib/screens/task_detail_screen.dart`。
- 普通任务卡展开预览位于 `lib/widgets/todo_item.dart`；预览区没有完整拖拽容器，因此仍保留上移 / 下移菜单，但图标、间距和危险操作样式已统一。
- 视觉回归测试位于 `test/task_detail_screen_test.dart`，基准图为 `test/goldens/subtask_detail_mobile.png`。
- 设计方向稿保存在 `docs/assets/子任务详情页统一方案.svg` 和同名 PNG。
