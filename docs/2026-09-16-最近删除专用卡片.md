# 最近删除专用卡片

> 日期：2026-09-16
> 数据库：v22，无迁移

## 已确认设计

![最近删除专用卡片方案](assets/最近删除专用卡片方案.png)

- 最近删除不再复用普通任务卡。
- 标题最多两行，不使用完成复选框和删除线。
- 来源标签与完整删除时间独立换行。
- 恢复按钮保持可见，永久删除收进带图标三点菜单。
- 320dp 和 360dp 使用底部操作行；更宽屏幕使用右侧操作区。
- 永久删除继续复用现有二次确认流程。

## 实现

- 新增 `DeletedTaskCard`，只负责回收站展示与两个动作回调。
- `TodoScreen` 的最近删除区域改用专用卡片。
- 新增 320/360/412dp 布局测试及永久删除菜单测试。

## 验证

- `git diff --check` 通过。
- 当前 Codex 环境中的 Flutter/Dart 命令启动无输出，自动化测试需在普通 PowerShell 补跑。

## 维护提示

回收站卡片不应重新加入任务完成、编辑、拖动或子任务操作；恢复位置由业务层现有来源规则处理。
