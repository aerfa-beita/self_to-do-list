# 本周历史完成任务显示修复

> 日期：2026-09-16
> 数据库：v22，无迁移

## 问题

本周组件已经实现“今天隐藏已完成、过去日期保留已完成”，但 `TodoScreen` 只把未完成任务传给组件，导致过去日期无法显示完成记录。

## 修复

- 本周数据源继续包含全部未完成任务。
- 额外传入 `completed_scope = week` 的已完成任务。
- 阶段和收件箱来源的完成任务不会混入本周历史。
- 今天和未来日期仍由本周组件过滤已完成任务；过去日期按照原定日期显示本周来源完成记录。
- 过去日期只有完成任务时默认收起，仍有未完成任务时自动展开。

## 验证

- 增加 TodoScreen 接线回归测试：过去未完成与本周完成可见，阶段完成不可见，今天完成不可见。
- `git diff --check` 通过。
- 当前 Codex 环境中 `flutter test`、单文件测试和 `dart format --output=none` 均在启动阶段无输出，已停止重试；需在普通 PowerShell 补跑完整测试。

## 维护提示

本周历史任务必须从 `completed_scope` 过滤，不能直接把全部已完成任务交给本周组件，否则会破坏来源隔离。
