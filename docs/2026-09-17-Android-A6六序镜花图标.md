# Android A6 六序镜花图标

> 日期：2026-09-17
> 方向：小花先生确认的 A6 六向万花筒

## 已完成内容

- 用 A6“六序镜花”替换 Flutter 默认启动图标。
- 六个独立棱镜模块围绕中心六边形旋转，每个模块由铂银、冷灰蓝和深灰蓝三个切面组成。
- 模块之间保留间隙，不使用两个重叠三角形，避免标准宗教六芒星轮廓。
- 中心六边形承载完成标记，48px 下仍保留主要轮廓。
- Android 8.0 及以上使用自适应图标，分别支持圆形、圆角方形和 Launcher 自定义遮罩。
- Android 13 及以上增加单色主题图标。
- Android 7.x 及以下提供 mdpi、hdpi、xhdpi、xxhdpi、xxxhdpi 五档普通与圆形 PNG。

## 资源结构

- 设计母版：`docs/assets/App图标-A6六序镜花.svg` 与 1024px PNG。
- 圆形母版：`docs/assets/App图标-A6六序镜花-圆形.svg` 与 1024px PNG。
- 自适应前景：`android/app/src/main/res/drawable/ic_launcher_foreground.xml`。
- Android 13 单色层：`android/app/src/main/res/drawable/ic_launcher_monochrome.xml`。
- 自适应入口：`mipmap-anydpi-v26`；带单色层入口：`mipmap-anydpi-v33`。
- 旧系统图标：五档 `mipmap-*dpi/ic_launcher.png` 与 `ic_launcher_round.png`。

## 验证

- 1024px 母版和 48px mdpi 普通、圆形图标已人工检查。
- 五档 PNG 尺寸和 ARGB 像素格式已检查。
- Android Build Tools 37.0.0 `aapt2 compile` 已通过全部 `res` 资源。
- Codex/JBR 的既有回环连接故障仍阻止 Gradle 构建；正式 APK 由普通 PowerShell 或 Android Studio 构建后做 Launcher 真机验收。

## 维护规则

- 修改图形时先更新 SVG 母版，再同步导出 PNG 和 VectorDrawable；不能只替换单个密度文件。
- 前景主体必须留在 Android 自适应图标安全区，圆形遮罩下不得裁切六个棱镜尖端。
- 禁止改成两个完整三角形叠加的标准六芒星；允许六向旋转，但必须保持模块分离。
