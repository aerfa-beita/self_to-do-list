# 双端应用图标同步

## 已完成内容

- Windows Runner 原先仍引用旧的 `windows/runner/resources/app_icon.ico`，与 Android 六序镜花资源不一致。
- 已用确认的六序镜花圆形母图生成 Windows 多尺寸 ICO，覆盖 16、24、32、48、64、128、256 像素。
- Android 应用显示名称由 `todo_list` 改为 `Stride`；包名、数据库路径和同步协议保持不变。

## 验收

- 源图人工检查通过。
- Android Release APK 内 `ic_launcher` 自适应图标资源已核对为六序镜花。
- Windows Release 需在本次 ICO 替换后重新构建，再检查 exe 属性和桌面快捷方式。

## 维护方式

- 修改图标时先更新 `docs/assets/App图标-A6六序镜花-圆形.png`，再重新生成 Windows ICO 和 Android 各密度资源。
- Windows 只使用 `windows/runner/resources/app_icon.ico`；Android 继续使用 `android/app/src/main/res` 下的 adaptive、monochrome 和旧系统 PNG。
- 改应用显示名称只修改 Android `app_name`、Windows 窗口标题或资源文本，不修改包名、数据库文件名和 Kotlin channel 名称。

## 潜在问题

- Windows 快捷方式可能继续显示旧图标，需要删除并重新创建快捷方式或重启资源管理器；不要清理用户桌面数据。
- Android 桌面启动器可能缓存旧快捷方式，但应用信息页应显示新图标；删除快捷方式并重新添加即可。
