## 可直接读取

- `front_idle/front_idle_000.png`：已统一到 512×512 透明画布，可直接作为第一版桌宠默认图。
- `celebrate/celebrate_001.png` ～ `celebrate_008.png`：完整人物透明帧，可按文件名顺序播放。
- `dragged/dragged_001.png` ～ `dragged_004.png`：完整人物透明帧，可循环播放。
- `avatar/windows_avatar_1024.png`：Windows 图标和托盘头像的高分辨率源图。
- 收起形态的 `*_72.png`：适合约 72×72 的桌宠收起窗口；`*_64.png` 和 `*_48.png` 用于更小显示测试。

## 仍需桌宠项目决定

- celebrate 与 dragged 的具体停顿时间、循环次数和状态切换逻辑。
- Windows `.ico` 是否需要 16/20/24/32/48/64/128/256 多尺寸封装。
- 收起形态最终采用 A、B 或 C；当前推荐 A，B 作为软萌备选。
- 点击区域是否按透明像素轮廓计算，还是固定为 72×72 正方形。
