## 行走脚底锚点规则

- `leftFootAnchor` / `rightFootAnchor` 均记录脚底实际接触点，不记录脚部图片中心。
- 脚跟接触到中支撑阶段，支撑锚点保持世界坐标不变。
- 提踵阶段锚点从脚跟过渡到前脚掌；脚尖离地后才解除锁定。
- 起步帧先前倾再位移；停止帧先缩短步幅再回正。
- `groundY` 同一方向、同一动作内固定；头部只做轻微上下起伏。

## 任务卡分层逻辑

任务相关动作的正式帧采用以下绘制顺序；第一阶段预览只验证遮挡关系，不导出正式分层帧。

1. `body_back/frame_XXX.png`：头、躯干、腿、位于任务卡后方的上臂与前臂。
2. 动态任务卡：由应用按 `taskSlot` 绘制标题和卡片。
3. `hands_front/frame_XXX.png`：压在卡片前方的手掌、手指和必要的短段前臂。

`taskSlot` 每帧记录 `centerX`、`centerY`、`width`、`height`、`rotationDeg`。`reach` 在双手接触前保持任务卡静止；`lift` 从握稳帧开始让任务卡跟随双手；`carry_left/right` 中任务卡相对双手保持不变；`put_down` 接触窝后保持任务卡位置，手部最后退出。

## 正式阶段每帧数据

- 画布：512×512。
- `groundY`。
- `leftFootAnchor`、`rightFootAnchor`，未接触地面时标记 `active: false`。
- `taskSlot`，非任务动作标记为 `null`。
- 方向使用解剖学与运动语义，左右素材独立绘制。
- 正式导出前统一线条粗细、人物占比、卡片尺寸、透明边缘和锚点精度。
