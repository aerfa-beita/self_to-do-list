# 角色一致性与可复用信息核验

## 原始人物身份锚点

- 黑色蓬松碎发，发顶有两簇上翘碎发。
- 大号矩形眼镜、黑色椭圆眼、小波浪嘴。
- 大头小身体，白色短袖、黑色短裤，赤脚。
- 三圈绷带固定在解剖学左前臂；正面观看时位于画面右侧手臂。
- 单耳环固定在解剖学右耳；正面观看时位于画面左侧耳朵。
- 暖棕色轮廓、黑色蜡笔填充、低饱和肤色与淡腮红。

## 现有正式素材可复用信息

- 512×512 组装坐标与 front / left / right 三方向构图比例。
- 左右方向独立资源规则，不做运行时镜像。
- 左右手抓握锚点、左右脚接触锚点、头部锚点、耳环轴点和任务卡中心的语义。
- 任务卡应始终处于双手之间，耳环只做滞后摆动。

## 不沿用的问题

- 不沿用散件独立旋转作为主要动作表现。
- 不沿用大跨度迈步、过量身体摇摆和脚底滑动感。
- 不沿用任务卡飞入手中的处理。
- 不沿用旧 reminder 的手铃；v2 改为举空手提醒。
- 不增加腿环、鞋子或其他新装饰。

## v2 第一阶段处理

- Chat 负责完整人物逐帧美术草图，原始人物图为最高身份参考。
- 左行和右行分别生成，避免镜像导致绷带与耳环换侧。
- 拖动采用肩臂放松、膝盖收放与脚尖延迟摆动。
- 搬运按减速、下蹲、双手接触、握稳、腿部起身、负重小步、接触窝、最后松手组织。
